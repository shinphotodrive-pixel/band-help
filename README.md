# 네이버 밴드 해킹 긴급 대처 센터 (Emergency Response Center)

네이버 밴드 계정 도용 및 리더(방장) 권한 탈취 피해 발생 시 즉각적인 초동 대처 및 1:1 고객센터 신고, 사이버수사국 신고 가이드를 제공하는 웹 서비스입니다.

## 주요 기능 (3대 탭 시스템)
1. **🚨 긴급 피해 복구 센터**:
   - 현재 피해 상황 실시간 집계 (피해 밴드 3곳, 권한 탈취자 이상철·전시숙, 확보된 URL 3개)
   - 긴급 초동 조치 가이드 (전 기기 강제 로그아웃, 비밀번호 변경 및 2FA 설정)
   - 1:1 고객센터 신고 내용 자동 생성기 (클립보드 원클릭 복사)
   - **밴드 회원 대상 비상 경고 문자/카카오톡 템플릿 복사기** (카카오톡 상세형, SMS/LMS 간결형, SNS 한줄형)
   - 경찰청 사이버범죄 신고시스템(ECRM) & KISA 118 신고 가이드
2. **🕵️‍♂️ 해커 잡는 방법 (신원 특정 및 법적 검거 가이드)**:
   - 결정적 스모킹 건(증거) 4대 패키지 (네이버 로그인 IP, 밴드 권한 탈취 알림, 프로필 화면, 금전 사기 계좌번호)
   - 경찰청 사이버수사팀 고소 & 영장 청구 유도 비법 (정보통신망법 제48조/제49조, 업무방해죄 제314조, 사기죄 제347조)
   - 경찰서 제출용 고소 요약문 자동 생성기 (원클릭 복사)
   - **경찰서 제출용 증거 자료 인쇄 / PDF 다운로드 모드** (공식 수사의뢰서 및 증거목록 A4 표준 서식, 실시간 입력 및 인쇄/PDF 저장 지원)
   - 경찰의 실시간 역추적 4단계 메커니즘 & 절대 하지 말아야 할 행동 수칙
3. **📂 유사 해킹 사례 분석 (최근 5개년)**:
   - 과거 5년간 네이버 밴드 해킹 주요 통계 및 트렌드
   - 대표 5대 유형(다중 가명 계정 숙청형, 반품마켓 입금 사기형, 악성 APK 유포형, 불법 리딩방 강제 개조형, 2FA 우회 스미싱형) 분석 및 실제 성공 대처법
   - 4대 핵심 재발 방지 매뉴얼

## GitHub Pages 배포 방법

### 1. GitHub에서 신규 리포지토리 생성
1. [GitHub](https://github.com/new)에 로그인하여 새 리포지토리(`band-emergency-help` 등)를 생성합니다.
2. `Public` 또는 `Private`을 선택합니다. (무료 계정에서 GitHub Pages 배포는 `Public` 권장)

### 2. 로컬 저장소와 원격 저장소 연결 및 푸시
터미널에서 아래 명령어를 실행하여 생성한 GitHub 리포지토리로 코드를 업로드합니다:

```bash
git remote add origin https://github.com/shinphotodrive-pixel/band-help.git
git push -u origin main
```

### 3. GitHub Pages 설정 활성화
1. GitHub 리포지토리 페이지의 **Settings > Pages** 메뉴로 이동합니다.
2. **Build and deployment > Source** 항목에서:
   - **GitHub Actions** 를 선택합니다. (제공된 `.github/workflows/deploy.yml`에 의해 자동 배포됩니다)
3. 푸시가 완료되면 몇 초 뒤 상단에 생성된 배포 URL (`https://<아이디>.github.io/<리포지토리>/`)로 웹페이지가 즉시 공개됩니다.
