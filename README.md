# 네이버 밴드 해킹 긴급 대처 센터 (Emergency Response Center)

네이버 밴드 계정 도용 및 리더(방장) 권한 탈취 피해 발생 시 즉각적인 초동 대처 및 1:1 고객센터 신고, 사이버수사국 신고 가이드를 제공하는 웹 서비스입니다.

## 주요 기능 (6대 탭 통합 원스톱 시스템)
1. **🚨 긴급 피해 복구 센터**:
   - 현재 피해 상황 실시간 집계 (피해 밴드 3곳, 권한 탈취자 이상철·전시숙, 확보된 URL 3개)
   - 긴급 초동 조치 가이드 (전 기기 강제 로그아웃, 비밀번호 변경 및 2FA 설정)
   - 1:1 고객센터 신고 내용 자동 생성기 (클립보드 원클릭 복사)
   - **밴드 회원 대상 비상 경고 문자/카카오톡 템플릿 복사기** (카카오톡 상세형, SMS/LMS 간결형, SNS 한줄형)
   - 경찰청 사이버범죄 신고시스템(ECRM) & KISA 118 신고 가이드
2. **🕵️‍♂️ 해커 잡는 방법 (신원 특정 및 법적 검거 가이드)**:
   - 결정적 스모킹 건(증거) 4대 패키지 (네이버 로그인 IP, 밴드 권한 탈취 알림, 프로필 화면, 금전 사기 계좌번호)
   - 경찰청 사이버수사팀 고소 & 영장 청구 유도 비법 (정보통신망법 제48조/제49조, 업무방해죄 제314조, 사기죄 제347조)
   - 경찰서 제출용 고소 요약문 자동 생성기 (원클릭 복사)
   - **경찰서 제출용 증거 자료 인쇄 / PDF 다운로드 모드** (공식 수사의뢰서 및 증거목록 A4 표준 서식, 실시간 입력 및 인쇄/PDF 저장 지원)
   - 경찰의 실시간 역추적 4단계 메커니즘 & 절대 하지 말아야 할 행동 수칙
3. **📂 유사 해킹 사례 분석 (최근 5개년)**:
   - 과거 5년간 네이버 밴드 해킹 주요 통계 및 트렌드
   - 대표 5대 유형(다중 가명 계정 숙청형, 반품마켓 입금 사기형, 악성 APK 유포형, 불법 리딩방 강제 개조형, 2FA 우회 스미싱형) 분석 및 실제 성공 대처법
   - 4대 핵심 재발 방지 매뉴얼
4. **👥 피해 회원용 (사기 피해 신고 및 계좌 지급정지 안내)**:
   - **송금 직후 10분 골든타임** 긴급 구제 가이드 (경찰청 112 / 금융감독원 1332 직통 연결)
   - **24시간 은행별 지급정지 긴급 직통 콜센터 디렉토리** (카카오·토스·국민·신한 등 14개 주요 금융사 직통전화 원클릭 연결, ARS 단축번호 안내 및 실시간 검색 필터)
   - **은행 상담원 연결 시 필수 통화 멘트 스크립트** (전화 걸고 즉시 읽을 수 있는 표준 문구)
   - **전기통신금융사기 피해환급 4단계 로드맵** (유선 지급정지 ➜ 경찰서 방문 및 사건사고사실확인원 발급 ➜ 3영업일 내 은행 피해구제신청서 제출 ➜ 금감원 채권소멸 환급)
   - **악성 링크(.apk) 클릭 및 앱 설치 시 스마트폰 긴급 조치 5계명** (비행기탑승모드, 시티즌코난 검사, 어카운트인포 전계좌 지급정지, 엠세이퍼 개통차단, 소액결제 0원 차단)
   - **방장 ➜ 피해 회원 1:1 긴급 대응 가이드 복사기** (사기 계좌 송금 회원용 / 악성 링크 클릭 회원용 맞춤 템플릿 & SMS 앱 바로 전송)
   - **피해 회원 필수 FAQ** (물품사기 지급정지 인정 여부, 계좌 잔액 소진 시 배상명령신청/소액심판 민사 청구, 간편송금 대처법, 공동 대응 노하우)
5. **🖼️ 카톡·밴드 단체방 배포용 (비상 경고 카드뉴스 이미지 생성기)**:
   - **1080x1080 고해상도 인스타그램/카카오톡 규격 캔버스 엔진 탑재** (순수 브라우저 Canvas 기반 무설치 생성)
   - 3가지 시각 테마 지원 (긴급 적색 경고형, 주의 황색 경보형, 사이버 다크모드)
   - 상황별 3대 프리셋 원클릭 로드 (권한 탈취 긴급 경고형, 반품마켓/특가 사기 주의형, 악성 링크/스미싱 주의형)
   - 탈취자 이름, 사기 의심 계좌번호, 주의 문구 실시간 입력 및 캔버스 자동 렌더링
   - **PNG 이미지 다운로드** 및 **클립보드 이미지 복사**(Ctrl+V 즉시 붙여넣기 지원)
   - 단체 카톡방/밴드 게시용 동반 배포 안내문 자동 서식 생성 및 복사
6. **🔍 사기 계좌·전화번호 실시간 이력 조회기 (경찰청 사이버캅 & 더치트 연동)**:
   - **원스톱 사기 이력 조회 검색창**: 계좌번호 및 전화번호 입력 후 경찰청 사이버범죄 신고 이력 및 더치트(TheCheat) 피해 사례 즉시 팝업 조회
   - **경찰청 사이버수사국 사이버캅(CyberCop)**: 최근 3개월간 3회 이상 사기 접수 이력 실시간 공공 데이터베이스 연동 안내
   - **국내 1위 금융사기 방지 민간 플랫폼 더치트(TheCheat)**: 100만+ 사기 데이터베이스 원클릭 조회 및 신규 사기 번호/계좌 즉시 등록 지원
   - **사기 의심 대포통장 4대 공통 특징 체크리스트** (인터넷전문은행 신규 개설 계좌, 예금주 불일치, 법인/유한회사 명의 계좌, 비정상적 빠른 계좌 교체)
   - **경찰서 제출용 증거 캡처(증 제5호) 생성 가이드** (계좌 조회 결과 화면을 수사기관 증빙자료로 공식 편철하는 요령)

## GitHub Pages 배포 방법

### 1. GitHub에서 신규 리포지토리 생성
1. [GitHub](https://github.com/new)에 로그인하여 새 리포지토리(`band-emergency-help` 등)를 생성합니다.
2. `Public` 또는 `Private`을 선택합니다. (무료 계정에서 GitHub Pages 배포는 `Public` 권장)

### 2. 로컬 저장소와 원격 저장소 연결 및 푸시
터미널에서 아래 명령어를 실행하여 생성한 GitHub 리포지토리로 코드를 업로드합니다:

```bash
git remote add origin https://github.com/shinphotodrive-pixel/band-help.git
git push -u origin main
```

### 3. GitHub Pages 설정 활성화
1. GitHub 리포지토리 페이지의 **Settings > Pages** 메뉴로 이동합니다.
2. **Build and deployment > Source** 항목에서:
   - **GitHub Actions** 를 선택합니다. (제공된 `.github/workflows/deploy.yml`에 의해 자동 배포됩니다)
3. 푸시가 완료되면 몇 초 뒤 상단에 생성된 배포 URL (`https://<아이디>.github.io/<리포지토리>/`)로 웹페이지가 즉시 공개됩니다.
